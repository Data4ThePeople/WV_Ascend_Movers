# WV_Ascend_Movers

Data 4 The People project, in progress. It looks at Ascend West Virginia, a
program that pays remote workers to move to West Virginia, and compares that
approach with JobsOhio's grants to companies. It also looks at other places
that have paid people to move and what their evaluations found.

No post or visualization is published yet. Links will be added here when they
are.

## What's in the repo

- `SCOPE.md`: the project scope, research questions, and candidate data sources
- `STATUS.md`: where the project stands in the publishing process

## Data sources

Planned sources are listed in `SCOPE.md`. They include Census population
estimates (components of change), IRS migration files, and published
evaluations of each program. A `DATASETS.md` file will describe each dataset
before analysis starts.
